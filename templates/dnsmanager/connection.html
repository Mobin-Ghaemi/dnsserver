راه‌اندازی اتصال

این مراحل را روی سرور انجام دهید.

SERVER SETUP
  1. ۱
    سرویس DNS را آماده کنید

    PowerDNS Authoritative را نصب و HTTP API را روی شبکهٔ خصوصی فعال کنید.

  2. ۲
    متغیرهای محیطی را تنظیم کنید

    در نصب مستقیم، تنظیمات خواندنی PowerDNS محلی خودکار خوانده می‌شوند. در صورت نیاز آدرس API، کلید و نام‌سرورها را در .env تعیین کنید.

    PDNS_API_URL=http://127.0.0.1:8081/api/v1
PDNS_API_KEY=your-private-api-key
PDNS_SERVER_ID=localhost
DNS_NAMESERVERS=ns1.your-domain.tld,ns2.your-domain.tld
  3. ۳
    پنل را راه‌اندازی مجدد و اتصال را تست کنید

    دامنه‌ها و رکوردهای موجود خودکار دریافت می‌شوند. برای دریافت بدون بازبودن مرورگر، دستور discover_dns را با timer اجرا کنید؛ جزئیات در README است.

در Docker، آدرس 127.0.0.1 داخل کانتینر به خود پنل اشاره می‌کند؛ نام سرویس یا مسیر شبکهٔ خصوصی DNS را استفاده کنید. جزئیات در README پروژه است.
